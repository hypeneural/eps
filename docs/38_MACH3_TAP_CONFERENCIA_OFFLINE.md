# Gerar arquivos TAP antes da homologação
A geração de bytes para conferência offline é independente do contrato físico. Use a nova rota para os nove modelos, sem solicitar novamente as informações documentais e sem criar flags de aprovação:
```powershell
python scripts/build_mach3_review_files.py --backup "private_evidence/MACROS_CNC_V.zip" --output outputs/mach3_review_9
```
Abra outputs/mach3_review_9/index.html para download individual local. Cada programa usa os parâmetros observados no isopor.pst (não limites autorizados), inclui aviso no próprio arquivo, leitura modal independente, simulação e hash. Nenhum perfil, contrato ou registro comercial é alterado. São arquivos para conferência offline, não executar na máquina. G54–G59 e G61/G64 não são assumidos. O diretório é privado, não constitui snapshot de produção e não deve ser hospedado publicamente.
O backup de 24/11 inclui 34 TAPs distintos e o pós-processador F600/S300/G4 P3; SoftLimit=0. Um programa antigo com X4100 mostra coordenadas históricas, não comprova curso útil. As capas H7 1250 e H7 1000 têm rebaixos nominais diferentes (25x15 e 27x15); não confundir. A geração offline não valida kerf, bloco, origem, I/O ou parâmetros atuais.
Para produzir programas executáveis aprovados, use a rota de teste supervisionado/revisão e publicação existente, docs/37. A aprovação deve corresponder aos bytes efetivamente testados. Não renomear candidato offline para programa comercial. A missão de geração offline requer nove arquivos reais; a missão de fabricação tem aceite separado check_mach3_delivery.py.
