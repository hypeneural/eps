# Render
Use GLB da mesma geometria, nunca imagem generativa como CAD. Execute scripts/render_quality.py --help. Com Blender 4.2+ use --blender e --input para GLB EPS ou conjunto. PNG separado do ZIP verificado. Abra a imagem e confira nervuras, topo plano, luz, textura e escala. Preview CPU e fallback, nao fotorealismo.
